## Small by design

TinyCMS borrows the content-on-disk feel of Ruby static-site generators while
remaining deployable on an ordinary PHP host.

- no database
- no browser-based admin area
- no package installation or build step
- content that remains readable in version control

## Maintenance mode

TinyCMS is feature-complete. Maintenance focuses on security, PHP compatibility,
and serious bugs. Start with the [about page](/about) or inspect the text files
under `pages/` to see how the example site is assembled.
